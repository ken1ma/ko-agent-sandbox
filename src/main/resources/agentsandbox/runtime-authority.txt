# The runtime authority (run-on-host.md "The Seatbelt profile"): paths the toolchain needs that
# are not the policy's own. One absolute path per line; prefix with "x " if it must also be
# executable. Entries resolve through realPath, so a symlink entry becomes a grant on its target;
# list a symlink's directory instead.
#
# Measured by `sh src/probe/build-profile-iterate.sh paths`, which grants every root entry and then
# removes them cumulatively — a tree stays only if the set without it stops working. Nothing here
# is reasoned about: the intuitive entries — /usr/lib, /System/Library, the dyld cryptexes —
# all measure as unnecessary, because the shared cache is mapped without any filesystem access.
#
# Grow it by running `floor`, which climbs from a shell to a real build and stops at the first
# rung that fails; the layer that failed names what to measure next.

# A shell. Everything in the launcher chain starts here.
x /bin

# The system tool directories. The launcher chain itself needs nine binaries from /usr/bin (env,
# uname, dirname, basename, readlink, expr, sed, grep, tr — src/probe/sbt-exec-chain.sh), but a
# build's own scripts call whatever they like: this repository's suite needs find and mount, and
# a profile that names tools one by one fails every project's tests differently. These are
# Apple-signed binaries whose effects on files and sockets are bounded by this same profile, so
# running them adds nothing the JVM could not do — except through Mach services, which is
# TODO.md's mach-lookup item, not a reason to name tools.
x /usr/bin
x /sbin
x /usr/sbin

# /private/var/select, whose one entry is the `sh` symlink /bin/sh consults to choose its
# personality. The shell runs without the read, so this row buys silence, not function: denied,
# every /bin/sh in the launcher chain complains "Error opening /private/var/select/sh" on stderr,
# and a benign line repeated on every build teaches readers to skip the stream where the real
# denials land. What it grants is one world-readable symlink naming the shell flavor.
/private/var/select

# The JVM reads the OS version from here; without it java refuses to start with
# "os.version malformed: -1.0". Measured by `paths`, which descended /System to this one file.
/System/Library/CoreServices/SystemVersion.plist
